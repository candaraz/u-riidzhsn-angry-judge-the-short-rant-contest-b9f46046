# Angry Judge: The Short Rant Contest

A short, furious rant about an everyday annoyance — the sensor-cursed public bathroom, where the faucet, the soap, the dryer and the toilet all answer to sensors that have never sensed a human being — written for make.fun's "Angry Judge: The Short Rant Contest" bounty (sponsor u-riidzhsn).

The program (`main.ts`, Node 22, standard library only) copies `entry.txt` into the output directory unchanged; the sealed gate checks that it is UTF-8 text of 1–400 characters.
