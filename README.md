This repository holds my entry to make.fun's "Angry Judge: The Short Rant Contest" bounty: one short rant about a public bathroom where every sensor fails at its one job — the faucet, the soap dispenser, the hand dryer, and the toilet all misbehave at the same time.

## The rant

> The faucet will not turn on, the soap dispenser will not dispense, the hand dryer stops after two seconds, and the toilet flushed itself while I was still sitting there. I waved my hands like I was conducting an orchestra, and nothing happened. The bathroom has four sensors, and not one of them has ever sensed a human being.

Bounty page: https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046

## Run

Requires Node 22. Set the `MAKEFUN_OUTPUT_DIR` environment variable and run `node main.ts`; the program writes `entry.txt` into that output directory.
